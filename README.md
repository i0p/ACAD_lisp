# ACAD AutoLISP

Коллекция полезных AutoLISP-функций для AutoCAD, предназначенных для автоматизации рутинных задач при проектировании систем вентиляции.

---

## 📦 Список функций

### 1. `DeleteAllWipeouts.lsp`

Удаляет все объекты `WIPEOUT` из чертежа.

- Удаляет объекты из пространства модели и листов.
- Обрабатывает определения блоков, включая вложенные блоки.
- Пропускает содержимое внешних ссылок (Xref).

**Команда запуска:** `DeleteAllWipeouts`

---

### 2. `DeleteAllSolidHatches.lsp`

Удаляет все штриховки с образцом `SOLID` из чертежа.

- Удаляет штриховки из пространства модели и листов.
- Обрабатывает определения блоков, включая вложенные блоки.
- Не затрагивает штриховки с другими образцами, например `ANSI31`.

**Команда запуска:** `DeleteAllSolidHatches`

---

## 🚀 Установка и использование

1. Скачайте нужный `.lsp`-файл из репозитория.
2. Откройте AutoCAD.
3. Выполните команду `APPLOAD`.
4. Выберите скачанный файл и загрузите его.
5. Введите соответствующую команду в командной строке AutoCAD.

---

## ⚠️ Важная информация

- Перед запуском рекомендуется сохранить резервную копию чертежа.
- Удаление объектов из определения блока влияет на все его вхождения.
- Функции не изменяют содержимое внешних ссылок (Xref).
- Результат работы зависит от структуры чертежа и доступности объектов для редактирования.
